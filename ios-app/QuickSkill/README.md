# QuickSkill — iOS Client 📱

Это нативный iOS-клиент для образовательной платформы **QuickSkill**. 
На данном этапе приложение реализовано в виде интерактивного MVP (Minimum Viable Product), который работает локально на устройстве и демонстрирует полный путь пользователя (User Flow).

## 🛠 Технологии
* **Язык:** Swift
* **UI-фреймворк:** SwiftUI
* **Архитектура:** MVVM (Model-View-ViewModel)
* **Медиа и файлы:** `PhotosUI` (галерея), `AVKit` (видеоплеер), `fileImporter` (импорт PDF/Видео)

## 🏗 Архитектура и переход на Backend (Для следующего потока)

Проект изначально спроектирован по паттерну **MVVM**, чтобы процесс подключения реального бэкенда (Django REST Framework + PostgreSQL) прошел максимально быстро и безболезненно.

**Важно для разработчиков следующего этапа:**
Вам **не нужно** переписывать дизайн, верстку или файлы экранов (`*View.swift`). Вся бизнес-логика и хранилище данных изолированы в одном месте. 

**Как подключить API:**
1. Откройте файл `AppViewModel.swift`.
2. Замените локальные модели (например, `LocalCourse`) на модели с поддержкой протокола `Codable` для парсинга JSON.
3. В методах ViewModel (таких как `loadInitialData` или `addCourse`) удалите локальное сохранение и добавьте сетевые запросы `URLSession` к вашим эндпоинтам.
4. Настройте передачу JWT-токенов в заголовках. 
*Интерфейс (Views) автоматически обновится, как только новые данные поступят в `@Published` переменные.*

## ✨ Реализованный функционал (MVP)
* **Просмотр и поиск курсов:** Динамическая лента с умным поиском (независимым от регистра) и фильтрацией по категориям.
* **Полноценная работа с медиа:** 
  * Загрузка фотографий для обложек напрямую из Галереи iPhone.
  * Интеграция локальных файлов: прикрепление PDF-документов и видеофайлов (.mp4, .mov).
  * Воспроизведение видео во встроенном системном плеере прямо внутри приложения.
* **Система рейтинга:** Кликабельные звезды для оценки курсов.
* **Форум:** Отдельный модуль для вопросов и обсуждений, адаптированный под светлую и темную темы.
* **Пользовательские настройки:** Локальное сохранение имени пользователя и выбор темы приложения через `@AppStorage`.

## 🚀 Запуск проекта
1. Склонируйте репозиторий.
2. Откройте проект в **Xcode 15.0** или новее.
3. Выберите симулятор (рекомендуется iPhone 15 Pro / 17 Pro).
4. Нажмите `Cmd + R` для сборки. Проект не требует дополнительных зависимостей (CocoaPods/SPM).
