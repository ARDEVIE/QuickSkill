# QuickSkill — iOS Client 📱

**QuickSkill** — это нативный iOS-клиент для образовательной платформы, предназначенной для создания курсов и обмена знаниями. На данном этапе проект реализован как интерактивный MVP, демонстрирующий ключевой пользовательский путь (User Flow) с использованием локального хранения данных.

## 🛠 Технологии
* **Язык разработки:** Swift
* **UI-фреймворк:** SwiftUI
* **Архитектура:** MVVM (Model-View-ViewModel)
* **Работа с медиа:** `PhotosUI` (доступ к галерее), `AVKit` (видеоплеер), `fileImporter` (импорт PDF и видео)

## ✨ Основной функционал
* **Каталог курсов:** Просмотр ленты, поиск без учета регистра и навигация по образовательным категориям.
* **Создание контента:** Загрузка обложек для курсов напрямую из Галереи устройства, прикрепление локальных PDF-документов и обучающих видеофайлов (.mp4, .mov).
* **Встроенный медиаплеер:** Воспроизведение загруженных видеороликов прямо в карточке курса через нативный системный плеер.
* **Форум:** Отдельный модуль для обсуждений, где пользователи могут задавать вопросы и взаимодействовать с сообществом.
* **Пользовательский профиль:** Управление данными профиля и системными настройками (смена имени, переключение светлой/темной темы) с сохранением состояния через `@AppStorage`.

## 🏗 Архитектура и масштабирование
Проект спроектирован с строгим соблюдением паттерна **MVVM**. Визуальные компоненты (Views) полностью изолированы от бизнес-логики и управления состоянием (ViewModel).

Данная архитектура обеспечивает бесшовный переход с локального хранения на реальный сервер (REST API). Для подключения бэкенда потребуется только модификация сетевого слоя внутри `AppViewModel` (интеграция `URLSession` и `Codable` моделей). UI-компоненты при этом останутся неизменными, так как они реактивно реагируют на изменения `@Published` свойств.

## 🚀 Установка и запуск
1. Склонируйте репозиторий на локальную машину.
2. Откройте файл `QuickSkill.xcodeproj` в **Xcode** (рекомендуется версия 15.0 и выше).
3. Дождитесь окончания индексации проекта.
4. Выберите целевой симулятор (например, iPhone 15 Pro) и нажмите `Cmd + R` для запуска.
> Примечание: Проект не использует сторонние менеджеры зависимостей (CocoaPods/SPM), сборка происходит моментально.
